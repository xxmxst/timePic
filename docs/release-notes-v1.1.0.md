# TimePic v1.1.0

本版本聚焦 Android 水印相机的操作效率和运行稳定性。

## Android 更新

- 扩大照片和相机预览区域，预览放置在底层，权限提示、顶部工具栏和底部拍照操作保持可点击。
- 将相册、闪光灯和更多设置放入顶部工具栏；备注、拍照和定位保留为主要操作。
- 拍照完成后自动保存到系统相册，编辑页仍可继续查看或分享结果。
- 增强图片导入和导出任务的取消、状态隔离和异常提示。
- 修复预览 Bitmap 生命周期竞态，降低图片切换时崩溃风险。
- 限制超大图片解码内存，清理无效草稿和未完成的相册写入记录。
- 增强配置版本标记和损坏数据的逐字段恢复能力。

## 验证

- JVM 单元测试通过。
